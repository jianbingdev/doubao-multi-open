## 本次更新

- **新增** 设置里可开启「下载改名」：5 种命名格式可选，也能用占位符自定义并实时预览（例如 `账号3-2026.11.10-奶白色钢制衣柜视频制作方案.mp4`）；默认关闭，关闭时保持原文件名，不生成任何清单文件
- **优化** 账号和设置的配置文件改成原子写入：先写临时文件 → 备份旧版 → 原子替换。读取失败时优先从备份恢复，坏文件另存 `.corrupt` 留证，不再自动覆盖
- **优化** 弹窗改成集合管理，同时开着多个弹窗时关掉其中一个，不会再让账号视图跳出来盖住另一个
- **优化** 批量发送的账号间隔等待可中断，点停止立即响应（原来要干等完当前那一轮间隔）
- **修复** 先开更新日志、再点版本号看更新时，更新弹窗被日志盖住（五个弹窗 z-index 相同，靠 DOM 顺序决定层级）
- **修复** 版本标签现在由程序运行时判断，正式版不会再冒出「开发版v」字样
- **修复** README 里写的默认下载目录与代码不一致（实际优先用系统「下载」文件夹）
- **修复** 补上 Node 版本要求，全新环境安装依赖不会装错版本

## 功能一览

多账号视图池 · 在线状态检测 · 套餐识别 · 跨账号完成提醒 · 视频生成后台等待
批量发送（纯文本 / 生成视频两种模式）· 图片多选复制 · 下载改名（多格式）· 账号右键菜单 · 内存回收 · 自动更新
